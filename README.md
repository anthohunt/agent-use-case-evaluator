# Agent - Use case evaluator

Work in progress.

You bring one task you want AI to do, with a few checked examples.
The agent runs that task on several models and deployments (people only, cloud AI, a small model on your own machine routed to a person or a cloud AI) and measures the same three things for each:

- time to set up, then time to run
- cost to set up, then cost of use
- quality, and what can go wrong

A person then chooses.

The skill and the agent are being defined; code will land here.
